## 📖 О проекте

**Mediana Research** — исследовательская компания, изучающая рынок алгоритмического трейдинга криптовалют **с 2021 года**. 

Проект нацелен на создание аналитических продуктов, которые помогают всем участникам инвестиционного рынка принимать взвешенные инвестиционные решения, основываясь на объективных данных:

* 📊 **Индекс MEDIANA** — ключевой композитный бенчмарк индустрии алготрейдинга.
* 📉 **Анализ доходности, убыточности и выживаемости** алготрейдинговых команд.
* 🔍 **OSINT-методология** — в основу исследований ложатся исключительно проверенные факты и данные из открытых источников, что обеспечивает независимость и доверие к результатам.
